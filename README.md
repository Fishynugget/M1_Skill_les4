## Werken met een online repository

Benodigdheden:

-Een github account

-een apparaat met genoeg opslag vrij

-een command terminal waar je bij kan

-git (dit is een aparte applicatie die je moet installeren)

### Extra informatie

Stap 1 : Maak een repository aan met een readme

Stap 2: Kopieer de link van de repository

Stap 3: Open de command prompt van jouw apparaat

Stap 4: Ga naar jouw gewenste directory

Stap 5: type in de command line: git clone(En zet daarachter de link naar de repository)

Stap 6: Maak wat veranderingen zoals: voeg mappen toe of schrijf wat in de readme

Stap 7: type: git status

Stap 8: type: git add . (om alle bestanden toe te voegen die je hebt gemaakt of veranderd)

Stap 9: type: git commit -m "Hier de naam van de commit"

Stap 10: type: git push

Stap 11: Controleer op github of je commit is toegevoegd
